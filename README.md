# WATBlocker

Oficjalne miejsce pobierania aplikacji WATBlocker dla Windows.

## Pobieranie

[Zobacz wydania WATBlockera](https://github.com/Ignacus58/WATBlocker-Downloads/releases)

Po opublikowaniu pierwszej wersji otwórz najnowsze wydanie i pobierz plik aplikacji z sekcji **Assets**. Archiwa oznaczone **Source code** są automatycznie tworzone przez GitHub i nie zawierają gotowej aplikacji.

## Status

Pierwsze wydanie jest przygotowywane. Sekcja Releases pozostanie pusta, dopóki nie opublikujemy sprawdzonej wersji aplikacji.
